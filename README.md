# Task 4 – Traffic Accident Analysis (Weather, Road & Hotspots)

## 🎯 Objective
Analyze accident patterns based on weather, derived road conditions, and time of day.
Visualize hotspots across locations.

## 🧰 Tools
Python | Pandas | Matplotlib | Seaborn | Folium

## ⚙️ Steps
1. Upload existing dataset (`US_Accidents_Sample.csv`).
2. Derive `Road_Condition` from weather & precipitation.
3. Perform EDA:
   - Weather condition distribution
   - Road condition frequency
   - Severity vs road condition
   - Hourly and daylight patterns
4. Create an interactive accident hotspot map.

## 📊 Output
- Interactive `us_accidents_hotspots.html` map
- Inline EDA charts
